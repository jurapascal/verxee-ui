Theming & dark mode

All colour decisions live in CSS variables. Override them after the stylesheet and the whole UI follows.

Light / dark

Theme is an attribute on <html>, shared with CoreUI: data-coreui-theme="light|dark". The runtime follows the OS preference until the user chooses, then remembers the choice in localStorage (verxee-ui-theme).

React to changes (e.g. to redraw a chart):

document.addEventListener('verxee:themechange', e => console.log(e.detail.theme));

Rebrand in one place

Change the accent and action colours (primary buttons, focus rings, links). Override both themes if the colour needs a lighter dark-mode variant.

:root, [data-coreui-theme="light"] {
  --admin-accent: #7C3AED;
  --admin-action: #7C3AED;
  --admin-action-hover: #6D28D9;
}
[data-coreui-theme="dark"] {
  --admin-accent: #A78BFA;
  --admin-action: #8B5CF6;
  --admin-action-hover: #7C3AED;
}

Change the font

:root { --admin-font: 'Geist', system-ui, sans-serif; }

Scoping a theme

Because variables cascade, a section can have its own theme: <section data-coreui-theme="dark"> re-skins everything inside it.

Status badge colours (.status--*) use fixed tints tuned for contrast in both themes. To change them, override the .status--success etc. rules, not the --admin-success variable (that one drives dots, borders and text).
