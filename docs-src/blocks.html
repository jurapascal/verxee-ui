Blocks

One vocabulary for the whole UI. A block is a plain object with a type. Put the same blocks in the topbar, the sidebar or the page — and nest them (a card contains a table, a grid contains cards).

VerxeeUI.app({
  topbar:        { left: [ … ], center: [ … ], right: [ … ] },   // blocks
  sidebarHeader: [ … ],                                           // blocks above the menu
  sidebar:       [ … ],                                           // nav items and/or blocks
  sidebarFooter: [ … ],
  page:          [ … ]                                            // blocks in the main area
});
VerxeeUI.mount('#panel', [ … ]);                                  // or render blocks anywhere

A block placed in an area it was not designed for still renders, but logs a console warning. List what is available at runtime with VerxeeUI.blocks().

Every block accepts

canPermission(s) needed — 'orders.view', ['a','b'] (any of) or (user) => bool. Not permitted → not rendered. UI convenience only, enforce on the server.
hidden · id · classNamePlain HTML attributes

Composing

page: [
  { type: 'heading', icon: 'users', title: 'Customers',
    actions: [{ type: 'search', onSearch: load }, { label: 'Add', variant: 'primary', size: 'sm', href: '#/new' }] },
  { type: 'stats', items: [{ icon: 'users', label: 'Total', value: 1204 }] },
  { type: 'grid', cols: 2, items: [
    { type: 'card', title: 'Recent', flush: true, body: [{ type: 'table', columns: [ … ], rows }] },
    { type: 'card', title: 'Add note', body: [{ type: 'form', fields: [{ name: 'note', label: 'Note' }], onSubmit: save }] } ] }
]

Your own blocks

VerxeeUI.register('clock', ['topbar', 'page'], (spec, ctx) => {
  const s = document.createElement('span');
  s.textContent = new Date().toLocaleTimeString();
  return s;                          // return a DOM node — use textContent, not innerHTML
});
// then: topbar: { right: [{ type: 'clock' }, 'user'] }
