Configuration

Describe your app in one object — sidebar, topbar, buttons, dialogs, look — and Verxee UI builds it. No markup to copy, nothing to rewire.

The shortest possible setup

Add a <main id="main"> with your page, then call VerxeeUI.app(). It wraps #main and creates the topbar, sidebar, mobile drawer and skip link.

VerxeeUI.app({
  theme:   { accent: '#7C3AED', radius: 'round', density: 'comfortable' },
  brand:   { name: 'Acme Admin', icon: 'bolt', href: '#/dashboard' },
  sidebar: [
    { label: 'Dashboard', icon: 'layout-dashboard', href: '#/dashboard' },
    { label: 'Orders',    icon: 'shopping-cart',    href: '#/orders', badge: 4 },
    { label: 'Catalog',   icon: 'tag', children: [
      { label: 'Products',   href: '#/products' },
      { label: 'Categories', href: '#/categories' } ] },
    { title: 'Admin' },
    { label: 'Audit log', icon: 'history', href: '#/audit' }
  ],
  sidebarFooter: [{ label: 'Settings', icon: 'settings', href: '#/settings' }],
  topbar: { right: [
    { label: 'New order', icon: 'plus', variant: 'primary', size: 'sm', onClick: () => openNewOrder() },
    { type: 'notifications', items: [{ icon: 'credit-card', title: 'Order #1042 paid', unread: true }] },
    'theme',
    { type: 'user', name: 'Jane Doe', menu: [
      { label: 'Profile', icon: 'user', href: '#/profile' },
      { divider: true },
      { label: 'Sign out', icon: 'logout', danger: true, confirm: { title: 'Sign out?' } } ] }
  ] }
});

See it running: examples/app.html. Prefer no JavaScript at all? Put the same object as JSON in <script type="application/json" data-verxee-config>…</script> (links, menus and badges work; callbacks need JS).

Sidebar items

ItemShape
Link{ label, icon, href, badge, active, onClick, confirm } — active is detected from the URL/hash; set it only to force it
Group{ label, icon, children: [links] } — opens automatically when a child is active
Heading{ title: 'Admin' }
Divider{ divider: true }

Change it later: const shell = VerxeeUI.app(…); shell.setSidebar(newItems) — e.g. after loading the user's permissions, so people only see what they may use.

Topbar items

topbar.left (after the brand) and topbar.right accept these:

ItemResult
'theme'Light/dark toggle
{ type: 'notifications', items, title, emptyText }Bell with unread counter and dropdown. Item: { icon, title, body, href, unread }
{ type: 'user', name, initials, menu }Avatar + dropdown menu
{ type: 'menu', label, icon, items, align }Any dropdown. Items: { label, icon, href, onClick, confirm, danger } or { divider: true }
{ type: 'html', html }Your own (trusted) markup
{ label, icon, variant, size, href, onClick, … }A button — see below

Replace it later with shell.setTopbar({ right: [...] }).

Buttons (actions)

Every button in the config — and VerxeeUI.button(spec) anywhere — uses the same spec:

Key
label, icon, titleText, Tabler icon name ('plus'), tooltip/aria-label. No label → icon-only button
variantprimary · secondary · ghost · danger · ghost-danger · warning · link
size'sm' or 'lg'
href / onClick(event, spec)Link or handler
confirmConfirm options ({ title, description, variant, … }) — asks first, runs the action only on OK
badge, disabled, className, id

Your own button variants

VerxeeUI.configure({ buttons: { brand: 'btn-primary my-brand-button', soft: 'btn-secondary' } });
VerxeeUI.button({ label: 'Upgrade', variant: 'brand' });

Defaults for popups

Set once, applies everywhere — including data-confirm attributes and buttons with confirm.

VerxeeUI.configure({
  toast:   { duration: 4000, position: 'top-right' },       // top|bottom + left|center|right
  confirm: { confirmText: 'Yes', cancelText: 'No',
             icons: { danger: 'alert-octagon' } },           // Tabler icon per variant
  modal:   { size: 'lg', closeOnBackdrop: false, okText: 'Save' }
});

Look & feel

configure({ theme }) — try every option live in the Customizer.

OptionValues
accent accentHoverAny CSS colour. Hover defaults to a darker mix
radius'sharp' · 'default' · 'round'
density'compact' · 'default' · 'comfortable' (control heights 30 / 34 / 38 px)
fontCSS font stack
sidebarWidthNumber (px) or CSS length
mode'light' or 'dark' (not saved)

Without JavaScript the same knobs are HTML attributes and CSS variables: <html data-vx-radius="round" data-vx-density="compact">, --radius-sm/md/lg/xl, --control-h, --sidebar-w, --admin-accent.
