Layout & page patterns

How to assemble the shell and the recurring page types.

Shell

Fixed .admin-topbar (48 px) + fixed .sidebar (240 px) + .admin-wrapper containing .admin-content. Below 992 px the sidebar becomes an off-canvas drawer and the content padding shrinks. Full markup: Installation.

Grids

.grid-2 (min 320 px columns) and .grid-3 (min 240 px) are auto-fit CSS grids with a 16 px gap — they collapse by themselves, no breakpoints needed. For anything else use Bootstrap's .row / .col-*, which CoreUI includes.

Print

The stylesheet includes print rules: chrome (topbar, sidebar, buttons) is hidden, content flows full width.
