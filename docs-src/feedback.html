Toasts, confirm dialogs, modals and popovers.

Toast

Call VerxeeUI.toast(message, options). The stack container is created automatically. Click a toast to dismiss it early.

OptionDefault
type—success | warning | critical | info; omit for the dark neutral toast
duration2500Milliseconds; 0 keeps it until clicked

Returns { close(), element }.

Confirm dialog

VerxeeUI.confirm(options) returns a Promise that resolves to true or false. Esc and a click on the backdrop cancel; focus is trapped and restored.

if (await VerxeeUI.confirm({ title: 'Delete?', variant: 'danger' })) {
  await deleteIt();
}

Options: title, description, confirmText (“Confirm”), cancelText (“Cancel”), variant (danger | warning | info).

No JavaScript needed for the common case — see data-confirm on Buttons.

Modal

Config-driven modals (VerxeeUI.modal, with form fields) are on the JavaScript API page. For markup-based modals and rich content use the CoreUI modal (it is restyled). Open it with data-coreui-toggle="modal".

Popover

.admin-popover is a lightweight arrowed panel for inline help. Place it inside a position: relative parent and choose .pop-above or .pop-below; .pop-fixed drops the arrow when you position it yourself.

Popovers are for short hints.
