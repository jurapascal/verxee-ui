Toasts, confirm dialogs, modals and popovers.

Toast

Call VerxeeUI.toast(message, options). Click a toast to dismiss it. The same message sent repeatedly is merged into one toast with a counter (×3) instead of stacking copies.

Look

Position

Every option can be set once for the whole app and overridden per toast:

VerxeeUI.configure({ toast: { position: 'top-right', style: 'soft', icon: null, closable: true, progress: true, duration: 4000, max: 4 } });
OptionDefault
type—success | warning | critical | info (colours the icon, border or background)
positionbottom-righttop | bottom + left | center | right
styledarkdark · light · soft · solid · accent
iconnullTyped toasts show their type icon automatically; false hides it, true forces one, or give any Tabler icon name
title—Bold first line
duration2500Milliseconds; 0 keeps it until dismissed
closable · progressfalse✕ button · countdown bar
max · dedupe5 · trueVisible toasts per corner (oldest removed) · merge identical toasts

Returns { close(), element }.

Confirm dialog

VerxeeUI.confirm(options) returns a Promise that resolves to true or false. Esc and a click on the backdrop cancel; focus is trapped and restored.

if (await VerxeeUI.confirm({ title: 'Delete?', variant: 'danger' })) {
  await deleteIt();
}

Options: title, description, confirmText (“Confirm”), cancelText (“Cancel”), variant (danger | warning | info).

No JavaScript needed for the common case — see data-confirm on Buttons.

Modal

Config-driven modals (VerxeeUI.modal, with form fields) are on the JavaScript API page. For markup-based modals and rich content use the CoreUI modal (it is restyled). Open it with data-coreui-toggle="modal".

Popover

.admin-popover is a lightweight arrowed panel for inline help. Place it inside a position: relative parent and choose .pop-above or .pop-below; .pop-fixed drops the arrow when you position it yourself.

Popovers are for short hints.
