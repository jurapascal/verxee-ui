Verxee UI

A small admin CSS framework in the Linear / Vercel spirit: neutral greys, one blue accent, a 4 px grid, Inter, and a proper dark mode. It is a skin on top of CoreUI 5 (Bootstrap-based), so you keep all CoreUI markup and JS.

Tokens

Every colour, shadow and gap is a CSS variable. Rebrand in one line, dark mode comes free.

Components

Buttons, badges, forms, tables, cards, sidebar, topbar, dialogs, toasts — consistent heights and spacing.

Tiny runtime

~12 KB of dependency-free JS: config-driven shell, modal, confirm, popover, toast, theme (VerxeeUI).

Quick start

Paste this into your <head> and you are done — no build step needed.

<html lang="en" data-coreui-theme="light">
<head>
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/jurapascal/verxee-ui@v2.1.0/vendor/coreui/coreui.min.css">
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/jurapascal/verxee-ui@v2.1.0/vendor/tabler-icons/css/tabler-icons.min.css">
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/jurapascal/verxee-ui@v2.1.0/dist/verxee-ui.min.css">
  <script defer src="https://cdn.jsdelivr.net/gh/jurapascal/verxee-ui@v2.1.0/vendor/coreui/coreui.bundle.min.js"></script>
  <script defer src="https://cdn.jsdelivr.net/gh/jurapascal/verxee-ui@v2.1.0/dist/verxee-ui.min.js"></script>
</head>

Principles

  • Variables first. Components read --admin-* tokens, never hard-coded colours (status badges excepted).
  • Fixed rhythm. Badges 22 px · buttons 28 / 34 / 40 px · inputs 34 px · topbar 48 px · sidebar 240 px.
  • Semantic buttons. Ordinary actions are blue, deletes red, edits orange.
  • Classes over inline styles. Use the utilities for the common cases.
  • Accessible by default. Visible focus ring, skip link, ARIA roles on dialogs and toasts.
