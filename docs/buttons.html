Buttons

Three sizes, five variants. Colour carries meaning: blue acts, red deletes, orange edits.

Variants

<button class="btn btn-primary">Primary</button>
<button class="btn btn-secondary">Secondary</button>
<button class="btn btn-ghost-secondary">Ghost</button>
<button class="btn btn-outline-danger">Delete</button>
<button class="btn btn-ghost-danger">Ghost danger</button>
<button class="btn btn-outline-warning">Edit</button>
<button class="btn btn-link">Link button</button>

Sizes

<button class="btn btn-primary btn-sm">Small 28</button>
<button class="btn btn-primary">Default 34</button>
<button class="btn btn-primary btn-lg">Large 40</button>

With icons

<button class="btn btn-primary"><i class="ti ti-plus"></i> New order</button>
<button class="btn btn-secondary btn--icon" aria-label="Settings"><i class="ti ti-settings"></i></button>
<button class="btn btn-ghost-secondary btn-sm btn--icon" aria-label="More"><i class="ti ti-dots"></i></button>

Icon-only buttons need an aria-label.

Disabled

<button class="btn btn-primary" disabled>Disabled</button>
<button class="btn btn-secondary" disabled>Disabled</button>

Confirm before acting

Add data-confirm to any button or link and the runtime shows a confirm dialog first; the original action only runs on “Confirm”.

<button class="btn btn-outline-danger" data-confirm="This cannot be undone." data-confirm-title="Delete order?" data-confirm-ok="Delete" onclick="VerxeeUI.toast('Deleted', {type:'critical'})"><i class="ti ti-trash"></i> Delete</button>
