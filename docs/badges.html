Badges & dots

One badge component (22 px) with six semantic colours. Pair it with a status — never use colour alone for meaning.

Status badges

Paid Pending Refunded Shipped In review Draft
<span class="status status--success">Paid</span>
<span class="status status--warning">Pending</span>
<span class="status status--critical">Refunded</span>
<span class="status status--info">Shipped</span>
<span class="status status--pending">In review</span>
<span class="status status--neutral">Draft</span>

.badge--success etc. are aliases, so CoreUI/Bootstrap .badge markup is restyled too.

Notification counter

Put .dot inside a .icon-btn and give it a number; hide it with hidden when the count is zero.

<button class="btn btn-ghost-secondary btn-sm icon-btn" aria-label="Notifications"><i class="ti ti-bell fs-5"></i><span class="dot">3</span></button>

Status-coloured selects

A <select class="form-select status-select-paid"> gets a coloured left edge. Available: -paid / -delivered (green), -shipped / -processing (blue), -pending / -awaiting_payment (orange), -cancelled / -failed (red).

<select class="form-select status-select-paid w-input-md"><option>Paid</option></select>
<select class="form-select status-select-pending w-input-md"><option>Pending</option></select>
<select class="form-select status-select-cancelled w-input-md"><option>Cancelled</option></select>
