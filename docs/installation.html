Installation

Three ways in: CDN, self-host, or npm. Load CoreUI first, Verxee UI second.

1 · CDN (jsDelivr)

Pin a version tag so updates never surprise you; use @main for bleeding edge.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/jurapascal/verxee-ui@v2.2.0/vendor/coreui/coreui.min.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/jurapascal/verxee-ui@v2.2.0/vendor/tabler-icons/css/tabler-icons.min.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/jurapascal/verxee-ui@v2.2.0/dist/verxee-ui.min.css">

With Subresource Integrity (the browser refuses a file whose hash does not match):

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/jurapascal/verxee-ui@v2.2.0/dist/verxee-ui.min.css"
      integrity="sha384-yzBHWonpCJ+pzMcEzoh8Dx4dhrgH/59HL4XjSTDizcq7d32yRf0yo9/eWfrEflxW" crossorigin="anonymous">
<script src="https://cdn.jsdelivr.net/gh/jurapascal/verxee-ui@v2.2.0/dist/verxee-ui.min.js"
        integrity="sha384-b7/Yy0qAVrJpQy4hXXkvpQNTVtxK9fsFcPYvoOEy0l+6Pmgis/GE3TWYvnmwtkTZ" crossorigin="anonymous"></script>

2 · Self-host

Clone or download the repository and copy dist/, fonts/ and vendor/ next to your app. Fonts are resolved relative to the CSS file (../fonts/), so keep that folder layout. Self-hosting is CSP-friendly and works offline (PWA).

git clone https://github.com/jurapascal/verxee-ui.git

3 · npm / build tools

npm install github:jurapascal/verxee-ui @coreui/coreui
import '@coreui/coreui/dist/css/coreui.min.css';
import 'verxee-ui/dist/verxee-ui.min.css';
import 'verxee-ui';              // sets up window.VerxeeUI

No flash of the wrong theme

The runtime applies the saved theme after load. To avoid a flash on first paint, put this tiny inline script in <head> before the stylesheets render:

<script>
  try { var t = localStorage.getItem('verxee-ui-theme');
        if (t) document.documentElement.setAttribute('data-coreui-theme', t); } catch (e) {}
</script>

App shell skeleton

The standard admin layout: fixed topbar, fixed sidebar, content wrapper. This is exactly what the demo uses.

<nav class="admin-topbar">
  <button class="btn btn-ghost-secondary btn-sm d-lg-none" data-sidebar-toggle aria-label="Menu"><i class="ti ti-menu-2"></i></button>
  <div class="brand"><a href="/"><span class="brand-logo"><i class="ti ti-layout-dashboard"></i></span> My app</a></div>
  <button class="btn btn-ghost-secondary btn-sm ms-auto" data-theme-toggle aria-label="Toggle theme"><i class="ti ti-moon"></i></button>
</nav>

<div class="sidebar sidebar-fixed" id="sidebar">
  <ul class="sidebar-nav" data-coreui="navigation">
    <li class="nav-item"><a class="nav-link active" href="#"><i class="nav-icon ti ti-layout-dashboard"></i> Dashboard</a></li>
  </ul>
</div>
<div class="sidebar-backdrop" data-sidebar-toggle></div>

<div class="admin-wrapper">
  <main class="admin-content"> … </main>
</div>
Icons. Verxee UI uses Tabler Icons: <i class="ti ti-settings"></i>. Any other icon font works too.

Browser support

Evergreen browsers. The sticky save bar uses :has() to pad the page (progressive enhancement — everything else works without it).

Building from source

node scripts/build.mjs   # css bundle + dist/ + docs/ (Node 18+, no dependencies)
