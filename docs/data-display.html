Table

14 px cell padding, no uppercase headers. Wrap in .table-responsive inside a .card. .table-hover highlights rows; .row-link + data-href makes a row clickable (wire up navigation yourself). Use .text-tabular for numeric columns and th[data-sort] with .sort-asc / .sort-desc for sortable headers.

OrderCustomerTotalStatus
#1042Jane Doe1 290 KčPaid
#1041John Smith590 KčPending
#1040Eva Nováková340 KčShipped
<div class="card"><div class="table-responsive"><table class="table table-hover mb-0">
  <thead><tr><th>Order</th><th>Customer</th><th data-sort class="sort-desc">Total</th><th>Status</th></tr></thead>
  <tbody>
    <tr class="row-link"><td><a href="#">#1042</a></td><td>Jane Doe</td><td class="text-tabular">1 290 Kč</td><td><span class="status status--success">Paid</span></td></tr>
    <tr class="row-link"><td><a href="#">#1041</a></td><td>John Smith</td><td class="text-tabular">590 Kč</td><td><span class="status status--warning">Pending</span></td></tr>
    <tr class="row-link"><td><a href="#">#1040</a></td><td>Eva Nováková</td><td class="text-tabular">340 Kč</td><td><span class="status status--info">Shipped</span></td></tr>
  </tbody></table></div></div>
data-sort only styles the arrow — sorting logic is yours (or your data-table library's).
