Sticky save bar

For long settings forms, add .page-actions-bar as the last child of the content. It pins to the bottom of the viewport (right of the sidebar) and the page pads itself so nothing hides behind it. Put a message in .page-actions-status — it is pushed to the left.

<div class="page-actions-bar">
  <span class="page-actions-status">Unsaved changes</span>
  <button class="btn btn-secondary">Discard</button>
  <button class="btn btn-primary">Save</button>
</div>
