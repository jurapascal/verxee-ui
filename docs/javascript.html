Modal

Plain dialog, or a form: pass fields and the promise resolves with the values.

<button class="btn btn-secondary" id="jm1">Dialog</button>
<button class="btn btn-secondary" id="jm2">Form</button>
<button class="btn btn-secondary" id="jm3">Custom buttons</button>
<script>
document.getElementById('jm1').onclick = () => VerxeeUI.modal({ title: 'About', text: 'Plain text content.', buttons: [{ label: 'Close', variant: 'primary', value: true }] });
document.getElementById('jm2').onclick = () => VerxeeUI.modal({ title: 'New customer', fields: [
  { name: 'name', label: 'Name', required: true }, { name: 'plan', label: 'Plan', type: 'select', options: ['Free', 'Pro'] } ] })
  .then(v => v && VerxeeUI.toast('Hello ' + v.name + ' (' + v.plan + ')'));
document.getElementById('jm3').onclick = () => VerxeeUI.modal({ title: 'Unsaved changes', size: 'sm', text: 'Save before leaving?', buttons: [
  { label: 'Discard', variant: 'danger', value: 'discard' }, { label: 'Cancel', variant: 'secondary', value: null }, { label: 'Save', variant: 'primary', value: 'save' } ] })
  .then(v => VerxeeUI.toast('Chose: ' + v));
</script>

Resolves with the pressed button's value (default buttons: OK = true, Cancel = false); closing with Esc, ✕ or the backdrop gives null. With fields OK gives { name: value } and required fields are validated. A button's onClick may return false (or a Promise of it) to keep the dialog open. Options: size sm | md | lg, closable, closeOnBackdrop. Field types: any input type, textarea, select (with options).

Popover

<button class="btn btn-secondary" id="jp1">Via JavaScript</button>

CoreUI components

Dropdowns, modals, collapse, tooltips and the sidebar's collapsible groups come from CoreUI's own JS (coreui.bundle.min.js) via data-coreui-* attributes — see the CoreUI docs.

Security

toast() and confirm() render text with textContent, so user-supplied strings are safe to pass. Escape anything you put into your own innerHTML.
