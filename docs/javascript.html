JavaScript API

One global, window.VerxeeUI, no dependencies, ~5 KB minified. Load dist/verxee-ui.min.js (with defer).

Overview

APIDescription
VerxeeUI.versionLibrary version string
VerxeeUI.theme.get()Returns 'light' or 'dark'
VerxeeUI.theme.set(mode, persist = true)Sets the theme; saves to localStorage unless persist is false
VerxeeUI.theme.toggle()Flips and returns the new mode
VerxeeUI.sidebar.open() · close() · toggle()Mobile off-canvas sidebar (#sidebar)
VerxeeUI.toast(message, { type, duration })Shows a toast; returns { close, element }
VerxeeUI.confirm({ title, description, confirmText, cancelText, variant })Promise<boolean>

CoreUI components

Dropdowns, modals, collapse, tooltips and the sidebar's collapsible groups come from CoreUI's own JS (coreui.bundle.min.js) via data-coreui-* attributes — see the CoreUI docs.

Security

toast() and confirm() render text with textContent, so user-supplied strings are safe to pass. Escape anything you put into your own innerHTML.
