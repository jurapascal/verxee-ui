Feedback

Toasts, confirm dialogs, modals and popovers.

Toast

Call VerxeeUI.toast(message, options). The stack container is created automatically. Click a toast to dismiss it early.

<button class="btn btn-secondary" onclick="VerxeeUI.toast('Settings saved')">Neutral</button>
<button class="btn btn-secondary" onclick="VerxeeUI.toast('Order marked paid', {type:'success'})">Success</button>
<button class="btn btn-secondary" onclick="VerxeeUI.toast('Low stock', {type:'warning'})">Warning</button>
<button class="btn btn-secondary" onclick="VerxeeUI.toast('Payment failed', {type:'critical', duration:5000})">Critical</button>
<button class="btn btn-secondary" onclick="VerxeeUI.toast('New version available', {type:'info', duration:0})">Sticky info</button>
OptionDefault
type—success | warning | critical | info; omit for the dark neutral toast
duration2500Milliseconds; 0 keeps it until clicked

Returns { close(), element }.

Confirm dialog

VerxeeUI.confirm(options) returns a Promise that resolves to true or false. Esc and a click on the backdrop cancel; focus is trapped and restored.

<button class="btn btn-outline-danger" onclick="VerxeeUI.confirm({title:'Delete customer?',description:'Their orders stay, but the profile is removed.',confirmText:'Delete',variant:'danger'}).then(ok => VerxeeUI.toast(ok ? 'Deleted' : 'Cancelled'))">Danger</button>
<button class="btn btn-secondary" onclick="VerxeeUI.confirm({title:'Discard changes?',variant:'warning'}).then(ok => VerxeeUI.toast(String(ok)))">Warning</button>
<button class="btn btn-secondary" onclick="VerxeeUI.confirm({title:'Send e-mail now?',description:'12 recipients.',confirmText:'Send',variant:'info'}).then(ok => VerxeeUI.toast(String(ok)))">Info</button>
if (await VerxeeUI.confirm({ title: 'Delete?', variant: 'danger' })) {
  await deleteIt();
}

Options: title, description, confirmText (“Confirm”), cancelText (“Cancel”), variant (danger | warning | info).

No JavaScript needed for the common case — see data-confirm on Buttons.

Modal

Config-driven modals (VerxeeUI.modal, with form fields) are on the JavaScript API page. For markup-based modals and rich content use the CoreUI modal (it is restyled). Open it with data-coreui-toggle="modal".

Add note

<button class="btn btn-primary" data-coreui-toggle="modal" data-coreui-target="#demoModal">Open modal</button>
<div class="modal fade" id="demoModal" tabindex="-1" aria-labelledby="demoModalTitle" aria-hidden="true">
  <div class="modal-dialog modal-dialog-centered"><div class="modal-content">
    <div class="modal-header"><h2 class="modal-title fs-md" id="demoModalTitle">Add note</h2><button class="btn-close" data-coreui-dismiss="modal" aria-label="Close"></button></div>
    <div class="modal-body"><label class="form-label" for="note">Note</label><textarea id="note" class="form-control" rows="3"></textarea></div>
    <div class="modal-footer"><button class="btn btn-secondary" data-coreui-dismiss="modal">Cancel</button><button class="btn btn-primary" data-coreui-dismiss="modal">Save</button></div>
  </div></div>
</div>

Popover

.admin-popover is a lightweight arrowed panel for inline help. Place it inside a position: relative parent and choose .pop-above or .pop-below; .pop-fixed drops the arrow when you position it yourself.

Popovers are for short hints.
<span style="position:relative;display:inline-block;margin-bottom:70px"><button class="btn btn-secondary">Anchor</button>
<div class="admin-popover pop-below p-3" style="width:220px">Popovers are for short hints.</div></span>
